# Topic 5 · Exercise 5.1 — deepClone руками · Solution

Реализовать `deepClone<T>(value: T): T` без `structuredClone`. Должна корректно обрабатывать примитивы, массивы, объекты, Date, Map, Set и циклические ссылки.

## Что нужно сделать

В `src/deep-clone.ts`:

- Примитивы / null / undefined — возвращать как есть
- `Date` — `new Date(value.getTime())`
- `Map` / `Set` — пройти по записям, рекурсивно клонировать
- Массивы и обычные объекты — обойти ключи рекурсивно
- Циклы — через `WeakMap<object, unknown>`. Перед клонированием объекта проверять кэш; если уже есть — вернуть оттуда. После создания клона записать его в кэш до рекурсивного обхода полей

## Критерии сдачи

- 14+ тестов в `tests/unit/deep-clone.test.ts` зелёные
- Тип-контракты в `tests/types/index.test.ts` зелёные (тип возврата = тип входа)
- `npm run check` зелёный
- Циклическая ссылка не уходит в бесконечную рекурсию
