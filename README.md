# Topic 4 · Exercise 4.1 — Builder для SQL-запроса

Сделать fluent API для сборки SELECT-запроса. Каждый метод возвращает builder, в конце `toSQL()` собирает строку и массив параметров для placeholder'ов `$1, $2, ...`.

## Что нужно сделать

В `src/query-builder.ts` реализовать все шесть методов:

- `select(...columns)` — сохраняет колонки. Без аргументов значит `*`. Возвращает `this`
- `from(table)` — сохраняет таблицу. Возвращает `this`
- `where(column, op, value)` — добавляет условие. Можно вызывать несколько раз, объединяются через `AND`. Возвращает `this`
- `orderBy(column, direction = 'ASC')` — добавляет сортировку. Возвращает `this`
- `limit(count)` — сохраняет лимит. Возвращает `this`
- `toSQL()` — собирает SQL. Если `from()` не вызывался — кинуть ошибку. Параметры выходят как `$1, $2, ...` в массиве `params` в порядке появления

## Канонический порядок частей

`SELECT ... FROM ... WHERE ... AND ... ORDER BY ... LIMIT ...`
