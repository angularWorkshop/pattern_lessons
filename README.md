# Topic 15 · Exercise 15.2 — CommandQueue с приоритетами

Реализуй очередь команд с поддержкой приоритетов и отмены до выполнения.

## Что нужно сделать

В `src/queue.ts`:

- `schedule(command, priority)` → возвращает `CommandId`. Положить в `items` запись `{ id, priority, command, cancelled: false }`, увеличить nextId
- `cancel(id)` → найти запись с этим id и поставить `cancelled = true`. Если id не найден — ничего не делать
- `runAll()` → отсортировать `items` по убыванию приоритета (стабильно — равные приоритеты сохраняют порядок добавления). Пройти по отсортированному массиву; cancelled пропускать, остальные — `command.execute()`. Вернуть массив id выполненных в порядке выполнения

## Главное

Стабильная сортировка — `Array.prototype.sort` в современных движках стабильна, но при равных ключах надо аккуратно сравнивать. Я бы добавил вторичный ключ — индекс добавления — чтобы было однозначно.
