# Design Patterns Exercise Standard

This repository stores EduTec Design Patterns course exercises.

## Branch naming

Every exercise has two branches:

- `lesson-topic-XX-exercise-YY-slug`
- `answer-topic-XX-exercise-YY-slug`

## Starter branch

- keeps TODO-style draft output in `src/index.ts`
- includes the same runtime and type tests as the answer branch
- must show `ASSIGNMENT STATUS: NOT COMPLETED` until the student finishes the task

## Answer branch

- returns `status: 'completed'`
- keeps expected artifacts in the exact tested order
- must show `ASSIGNMENT STATUS: COMPLETED`
